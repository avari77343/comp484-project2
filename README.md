# Pixel Pals — Giga Pet

A small browser-based virtual pet game built with HTML, CSS, JavaScript, and jQuery.

## Features
- Treat, Play, Exercise, and Nap actions update Mochi's stats.
- Weight and happiness are protected from going below zero; happiness is capped at 10.
- Mochi displays a different comment after each action.
- Rename the pet using a text input.
- Uses the jQuery `.val()` and `.replaceWith()` methods, documented in `script.js`.
- Responsive layout and an original SVG pet illustration.

## Run locally
Open `index.html` in Chrome while connected to the internet (the page loads jQuery from its CDN).
